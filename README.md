# 空き教室検索サイト

横浜国立大学の理工棟Aを対象に、曜日・時限ごとの空き教室を確認できる非公式Webサイトです。

**公開URL：[https://rumors0801.github.io/classroom-search/](https://rumors0801.github.io/classroom-search/)**

## 主な機能

- トップページに今日の曜日の空き状況を表示
- 指定した曜日の空き状況を一覧表示
- 各教室の1〜7限の利用状況を「空」「満」で表示
- コンセントの有無を表示

現在の登録対象は理工棟Aの23教室で、対象学期は **2026年度秋学期** です。月曜日〜日曜日のデータを収録しており、登録データの更新日は **2026-11-20** です。土日は全教室・全時限が空きとして登録されています。

## 使い方

1. 公開URLにアクセスします。
2. 場所と曜日を選択します。現在、場所は「理工棟A」のみです。
3. 「この条件で調べる！」を押すと、選択した曜日の一覧を表示します。

表示は `datas/data2026fall.json` に登録されたデータに基づきます。リアルタイムの在室状況や、臨時の教室利用を取得する機能はありません。データの出典や現地での最終確認日は、リポジトリ内に記載されていません。

## 使用技術

- HTML / CSS
- JavaScript（ES Modules）
- JSON（Fetch APIで教室データを読み込み）
- Google Fonts

バックエンドやデータベースを使わず、ブラウザ上で動作する静的サイトです。ビルドやパッケージのインストールは不要です。

## ローカルでの確認

ES ModulesとFetch APIを使用しているため、HTMLファイルを直接開くのではなく、HTTPサーバー経由でアクセスしてください。

Pythonがインストールされている場合は、リポジトリのルートで次を実行できます。

```sh
python -m http.server 8000
```

起動後、ブラウザで [http://localhost:8000/](http://localhost:8000/) を開きます。サーバーは `Ctrl+C` で停止できます。

## 教室データの更新

`datas/data2026fall.json` の `metadata` に学期などの情報を、`classrooms` に教室ごとの情報を記述します。以下はA101のみを記載した形式例です。

```json
{
  "metadata": {
    "academicYear": 2026,
    "semester": "fall",
    "periodsPerDay": 7,
    "updatedAt": "2026-11-20"
  },
  "classrooms": {
    "A101": {
      "building": "rikoA",
      "hasOutlets": false,
      "schedule": {
        "Sunday": [0, 0, 0, 0, 0, 0, 0],
        "Monday": [0, 1, 0, 0, 0, 0, 0],
        "Tuesday": [1, 1, 0, 1, 0, 0, 0],
        "Wednesday": [1, 1, 0, 0, 0, 0, 0],
        "Thursday": [0, 1, 1, 0, 0, 0, 0],
        "Friday": [0, 0, 0, 0, 0, 0, 0],
        "Saturday": [0, 0, 0, 0, 0, 0, 0]
      }
    }
  }
}
```

- `metadata`：年度、学期、1日あたりの時限数、データ更新日
- `classrooms` のキー：教室名（例：`A101`）
- `building`：建物の識別子（現在は `rikoA`）
- `hasOutlets`：コンセントの有無（`true` / `false`）
- `schedule`：`Sunday`〜`Saturday` の各曜日について、1〜7限の状態を並べた数値配列。`0` は空き、`1` は使用中

例えば `[0, 1, 0, 0, 0, 0, 0]` は、2限のみ使用中であることを表します。JSONにはコメントや末尾の余分なカンマを記述できません。

学期を切り替える場合は、新しいデータファイルを追加したうえで、`index.js` と `searched.js` の読み込み先を両方変更してください。両HTMLの学期表記と、このREADMEの対象学期・更新日も合わせて更新します。

変更後は、トップページと曜日を指定した検索結果の両方で、教室名・各時限の状態・コンセントの有無を確認してください。土日も確認対象に含めます。

## 現在の制限・既知の問題

- 場所によるデータの絞り込みは未実装です。`building` とURLの `place` パラメータは、現在の表示処理では使用していません。
- `searched.html` を曜日パラメータなし、または不正な曜日で開くと、結果の行と曜日名は表示されません。案内メッセージや既定の曜日への切り替えは未実装です。
- データの読み込みに失敗した場合、画面上にエラーを案内する処理はありません。
- `metadata` は表示に自動反映されません。学期名と時限数はHTMLにも記述されており、JavaScriptの表生成も7時限固定です。
- 土日の「空」は登録値に基づく表示で、施設の開放や利用許可を保証するものではありません。
